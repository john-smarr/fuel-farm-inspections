# P66 Fuel Farm Inspector — Usage Workflow

---

## First-Time Setup

1. Open the app and tap **Settings** (bottom right)
2. Tap **Add** and enter your facility ID (e.g. `PDX-01`) and full name
3. Tap **Save Facility** — it becomes your active facility automatically
4. Optionally add email addresses under **Email Alert Recipients** to receive failure notifications

---

## Daily Inspection

Do this once per day, every day.

1. Tap **Daily** (bottom left)
2. The calendar shows the current month — tap **Log Today's Inspection**
3. Fill in **Manager / Trainer** name
4. Work through the 7 checklist items — toggle each **Pass** or **Fail**
   - If you mark anything **Fail**, a note field opens — describe the issue (required)
   - Optionally take a photo of the problem
5. Set the **Tank Sump** code using the Solids (1–4) and Water (A–E) pickers
6. Set the **Filter Vessel Sump** code the same way
   - Tap **?** at any time to open the reference legend if you need a reminder
7. Enter the **DP Pressure** reading
8. Add any **Comments** (optional)
9. Enter your **Signature** (full name)
10. Tap **Save Inspection**
    - If there were failures and email recipients are configured, tap **Send Email Alert**

**Calendar color guide:**
- 🟢 Green dot = all items passed
- 🟡 Yellow dot = one or more failures
- No dot = no entry yet

---

## Monthly Inspection

Do this once per month, typically on the same date each month.

1. Tap **Monthly** (bottom middle)
2. Confirm the correct month is shown (use arrows to navigate if needed)
3. For each of the 9 items, select a rating:
   - **S** — Satisfactory
   - **C** — Comment required (maintenance action notes become mandatory)
   - **N/U** — Not Used
   - **N/A** — Not Applicable
4. For numeric items, enter the reading:
   - Anti-Icing Additive (target: 0.10–0.15 VOL%)
   - Free Water (ppm)
   - Bonding Cable Continuity (must be ≤ 25Ω)
5. Fill in **Date** and **Signature** for each item
6. For any **C**-rated item, fill in **Maintenance Action Notes** (required)
7. Tap **Save Inspection**
   - If there were C-rated items and recipients are configured, tap **Send Email Alert**

---

## Exporting / Printing Records

- Open any saved daily or monthly inspection
- Tap the **print icon** (top right of the form)
- On web/desktop: tap **Print** to send to a printer or save as PDF
- Records show facility info, all checklist results, sump codes, readings, and signatures

---

## Reference Legend

Tap the **?** button (floating, bottom right of the Daily or Monthly screen) at any time to view:
- Solids codes 1–4 (Clear → Dirty)
- Water codes A–E (Bright & Clear → Surfactants/Foam)
- Fuel color guide (Jet A: white/light straw · 100LL AvGas: blue)

---

## Data & Backup

All data is stored locally on the device. To avoid data loss:
- Go to **Settings → Export** regularly to download a backup file
- To restore on a new device: **Settings → Import** and select the backup file
